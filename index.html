HTML

O que significa a sigla HTML?

Resposta

HyperText Markup Language (Linguagem de Marcação de Hipertexto).

CSS

Para que serve o CSS?

Resposta

Para estilizar e definir o layout visual das páginas web.

JavaScript

Qual a principal função do JavaScript?

Resposta

Adicionar dinamicidade e interatividade às páginas web.

DOM

O que é o DOM no desenvolvimento web?

Resposta

Document Object Model: a representação em estrutura de árvore dos elementos do HTML.

API

O que é uma API?

Resposta

Application Programming Interface: um conjunto de regras que permite a comunicação entre sistemas.
